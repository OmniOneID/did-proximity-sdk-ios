# iOS mdoc Proximity SDK

Welcome to the iOS mdoc Proximity SDK Repository. <br>
This repository provides an SDK for ISO/IEC 18013-5 device retrieval on iOS — presenting an mdoc from a holder app (mdoc) and requesting and verifying it from a verifier app (mdoc reader) over QR or NFC engagement and BLE or NFC data retrieval.

## Libraries

Libraries can be found in the [releases folder](source/release).

### mdoc Proximity SDK

1. Copy the `MdocProximitySDK.xcframework` file to the framework directory of the app project.
2. Add the framework to the app project dependencies.
3. Set the framework to `Embed & Sign`.
